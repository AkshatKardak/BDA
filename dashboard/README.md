# IPL Big Data Analytics: Streamlit Interactive Dashboard

## 1. Overview
The interactive dashboard serves as the presentation layer for the Big Data pipeline.
It connects directly to the analytical outputs generated by Apache Flume, HDFS, Hive, and PySpark stored in the `output/` directory.

> **Academic Rule**: The dashboard reads pre-computed lake outputs (`output/*.csv`). It does **not** recalculate the 295,000+ ball-by-ball deliveries locally using Pandas.

---

## 2. Dashboard Sections
1. **Tournament Overview**:
   - High-level KPIs: 1,243 matches, 295,732 deliveries, 15 franchises, 60 venues, 18 seasons.
   - Conceptual architecture diagram.
   - Cumulative scoring per season.
2. **Franchise Performance**:
   - All-time franchise victories and win percentages.
   - Batting-first vs chasing victory distribution.
   - Head-to-head rivalry matrix.
3. **Player Leaderboards**:
   - Top 10 run scorers, strike rates, batting averages, boundaries.
   - Top 10 wicket takers, economy rates, dot ball percentages.
4. **Toss Impact Dynamics**:
   - Toss decision distribution (Bat vs Field).
   - Toss winner match victory correlation.
   - Season-by-season evolution of toss advantage.
5. **Stadium & Pitch Insights**:
   - Average 1st innings par scores vs 2nd innings scores across stadiums.
   - Venue-specific win bias (Bat-First vs Chase).
6. **Season Macro-Trends**:
   - Run rate trajectory (Runs per over) across 18 editions.
   - Evolution of sixes and fours hit per season.
7. **Pre-Match ML Predictor**:
   - Pre-match outcome forecasting model evaluation.
   - Interactive matchup simulator.

---

## 3. Running the Dashboard
Ensure dependencies are installed:
```bash
pip install streamlit plotly pandas
```

Launch the application:
```bash
streamlit run dashboard/app.py
```
Or with custom port:
```bash
streamlit run dashboard/app.py --server.port 8501
```
Open your browser at `http://localhost:8501`.
